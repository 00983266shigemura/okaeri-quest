# おかえりクエスト

幼児向けの「帰宅後タスクチェック」Webアプリ。

## 特徴

- タスクを1つ達成するごとにスタンプと効果音が出る
- 全部達成すると花丸とごほうび動画タイム（時間が来ると自動で終了）
- 動画は「まえ／つぎ／えらぶ」に加えて、10秒早送り・10秒巻き戻し・再生位置バーで操作できる（字幕は自動でオフ）
- いつもの平均より早く終わるとボーナス時間が加算される
- ねる前のタスク（歯みがき等）の後にプチごほうびタイム
- 毎日最後まで完了するとスタンプが1個たまり、10個でスペシャルごほうび（初回は「カブトムシロボ」）
- 設定はすべて index.html の DEFAULT_SETTINGS でPC管理。端末の設定画面（算数ロック付き）は記録確認・やり直し専用
- 起動時に version.txt を見て、新しい版があれば自動で取り直す（iPadに直しが届かない問題への対処）

## 改修したときの手順

1. `index.html` の `var APP_VERSION = N;` を +1 する
2. `version.txt` に同じ数字を書く
3. `python3 tools/check_version.py` で PASS を確認する（2つの数字の食い違い検出）
4. コミットして push する

APP_VERSION は2つの役目を1つの数字で持つ。①端末の設定を DEFAULT_SETTINGS で上書きする
②端末が古いファイルを持っていたら `?v=新しい数字` へ移って取り直させる。
利用者はURLを打ち替える必要がない（アプリが自分で移る）。

## 動作環境

- iOS 10 Safari（iPad 第4世代など）でも動くよう、古いブラウザ互換の書き方（ES5）で作成
- HTML 1ファイル完結・サーバ処理なし・記録は端末内（localStorage）に保存
