# おかえりクエスト

幼児向けの「帰宅後タスクチェック」Webアプリ。

## 特徴

- タスクを1つ達成するごとにスタンプと効果音が出る
- 全部達成すると花丸とごほうび動画タイム（時間が来ると自動で終了）
- いつもの平均より早く終わるとボーナス時間が加算される
- ねる前のタスク（歯みがき等）の後にプチごほうびタイム
- 設定画面（かんたんな算数ロック付き）でタスク・時間・動画URLを変更できる

## 動作環境

- iOS 10 Safari（iPad 第4世代など）でも動くよう、古いブラウザ互換の書き方（ES5）で作成
- HTML 1ファイル完結・サーバ処理なし・記録は端末内（localStorage）に保存
